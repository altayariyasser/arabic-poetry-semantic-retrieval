# Release scope

Adapted from the existing `delivery/Arabic_Poetry_Retrieval` package, itself assembled from the final Plan B application. The original project is preserved. This release moves imports into `src`, allows an external artifact directory and configurable binding, and improves release documentation/tests. Ranking behavior and model weights are unchanged.

No corpus, embedding matrices, model weights, personal files, Fanar generation code or original test split is distributed. No new relevance judgments, fine-tuning, final evaluation or dataset approvals are claimed. Poetry screenshots are local-only until reuse rights are resolved. Code licensing has not been assigned on the owner's behalf; no open-source license grant is implied.
